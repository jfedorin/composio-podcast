# Agents at Work — Episode Hub

A single-page episode hub for **Agents at Work**, Composio's founder podcast hosted by Julia Fedorin.

- `index.html` — the entire site (no build step, no dependencies).
- Deployed on Vercel; pushes to `main` redeploy automatically.

## Add an episode
Open `index.html`, copy any block inside the `EPISODES` array, paste it at the top,
set the `youtubeId`, and push. Done.
